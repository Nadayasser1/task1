# Soccer League Games – Task 1

This project is the implementation of Task 1 using Java and Object-Oriented Programming (OOP).

The program simulates a simple soccer league. It creates two teams with their players, creates a match between them, and records the goals scored during the match.

### Classes

* **Player:** Stores player information such as name, ID, and team name.
* **Team:** Stores the team name, its players, total goals, and points.
* **Goal:** Stores the match ID, the player who scored, and the goal minute.
* **Match:** Contains the home team, away team, and the list of goals.
* **Schedule:** Manages the teams and matches, updates goals and points, ranks the teams, and displays the league table and match details.

### Main

The `Main` class creates the players and teams, creates a match, displays the league table before the match, displays the players of each team, adds the match goals, displays the match result and goal details, and finally displays the updated league table.
